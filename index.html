06 / FAQ

Ən çox soruşulanlar.

Qısa cavablar. Daha konkret hal üçün əlaqə formasından layihəni təsvir edə bilərsiniz.

Bəli. Mövcud 1C quruluşu, POS, vergi kassası və anbar avadanlığının bir-biri ilə necə işlədiyi əvvəlcə analiz edilərək uyğun inteqrasiya modeli qurulur.

Qurulan inteqrasiyanın məqsədi məlumatın təkrar daxil edilməsini azaltmaq və satış məlumatının kassa ilə proqram arasında avtomatik ötürülməsini təmin etməkdir.

Bəli. API vasitəsilə məhsul, satış və digər uyğun məlumat axınları qurula bilər. Konkret imkanlar istifadə olunan platformanın API-sinə və biznes prosesinə görə müəyyənləşdirilir.

AnyDesk proqramı rəsmi mənbədən yüklənir. İstifadəçi proqramdakı ID-ni paylaşır, sonra əlaqələndirilmiş sessiya üzərindən texniki problem yoxlanılır.
